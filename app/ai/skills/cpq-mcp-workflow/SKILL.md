# CPQ MCP Workflow

You have access to tools to interact directly with CPQ BML code via the MCP Server:
1. `pull`: Pull BML from the environment.
2. `edit`: Edit the BML.
3. `lint`/`validate`: Verify the BML syntax.
4. `save`/`deploy`: Save to the CPQ environment.

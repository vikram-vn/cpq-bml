## Reference

Reference topics are especially useful if you're new to REST APIs. You can start by reviewing commonly used REST API terms and the different types of [REST resources](Resource_Types.html), such as singular and collection resources. Explore the following topics:

| Topic | Description |
| --- | --- |

| [Status Codes](Status_Codes.html) | Lists status codes returned by the response header to indicate the general classification of the response. |
